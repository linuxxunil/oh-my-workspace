# Overlays / 浮层契约

本包的浮层基元拥有挂载点、层级、焦点、模态与关闭契约。业务按语义选用基元并组合其导出结构，不重造这些职责。

## 挂载与寿命

浮层内容经 `Teleport` 渲染到 `body`。`DialogContent` 类组件内部自带传送；显式结构的基元暴露传送与内容两部分。

根的 Vue 寿命、打开态、传送子树是否存在三者分离，存在性以各基元契约为准。`Dialog` 根可保持挂载并独立受控，不随内容关闭而卸载；用关闭条件同步卸载受控根会跳过关闭过渡。

挂载中内容子树可作为单次会话状态的归属方；需跨卸载存活的状态归显式长寿命业务方。卸载只重置子树内状态，祖先与外部存储不受影响。仅靠传送位置不构成重置边界。

宿主在应用根建立隔离层叠上下文：

```vue
<template>
  <div class="isolate h-full"><slot /></div>
</template>
```

等价 CSS 为 `isolation: isolate`，防止应用内高 z-index 与传送到 body 的浮层竞争。传送解决祖先裁剪，隔离本身不修裁剪。

## 层级

| 层 | z-index |
|---|---|
| 对话框、选择器、抽屉、菜单、浮层、预览卡、提示 | `z-50` |
| Toast 视口 | `z-60` |

`z-50` 层按传送挂载顺序，后挂在上。Toast 高一层。

- 调用方不加 `z-*` 覆盖；被裁剪去修归属结构。
- 不在基元浮层外再包一层手写传送。
- 共享遮罩与装饰放在归属导出组件内，不放调用方。

## 语义选型

- `Dialog`：需焦点约束与滚动锁定的模态内容。
- `AlertDialog`：仅破坏性或必须明确答复的确认。
- `Drawer`：侧边面板交互。
- `DropdownMenu`：按钮触发的动作列表；`ContextMenu` 给上下文动作。
- `Tooltip`：已有主动作与可访问名的控件补充标签；信息图标点开展开说明用 `Infotip`，按其组合与命名契约。
- `PreviewCard`：链接目标的非交互增强，关键信息不只存在于预览。
- `Popover`：触屏与无障碍必须可达的解释性、结构化、交互内容。

触发器用真实 `<button type="button">`；基元负责定位与间距，无文档化例外不覆写。
