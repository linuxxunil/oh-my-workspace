# UI Package Index / 基元索引

本包对外子路径唯一索引，新增基元在此登记。

| 子路径 | 内容 |
|---|---|
| `@/packages/ui/button` | 按钮、图标按钮 |
| `@/packages/ui/input-group` | 复合输入 |
| `@/packages/ui/input` | 文本输入、多行输入 |
| `@/packages/ui/form` | 表单、字段、校验 |
| `@/packages/ui/overlay` | 对话框、菜单、浮层、提示 |
| `@/packages/ui/selection` | 选择器 |
| `@/packages/ui/badge` | 语义徽标 |
| `@/packages/ui/empty-state` | 空态 |

新增基元四件套：公开类型、实现、测试、示例与文档，缺一不合入。
