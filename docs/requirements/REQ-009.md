# REQ-009 全站 Layout 与导航 UX 优化

> Origin: 用户 2026-09-29 定项——固定顶栏；桌面侧栏收窄/展开；手机 Drawer；用户菜单提供登出/修改密码；修改密码仅从用户菜单进入。

- 背景 / Background：`web/src/App.vue` 当前是固定宽度侧栏，用户信息与登出固定在侧栏底部；`/account` 已有修改密码页。共享 UI overlay 文档列出 `DropdownMenu`/`Drawer`，但源码无实现。
- 目标 / Goals：
  1. 登录后显示固定顶栏和当前用户；点击用户打开动作菜单，可进入 `/account` 修改密码或登出。
  2. 桌面侧栏可收窄/展开，收窄状态仍能辨认并访问导航；记忆该低频 UI 偏好。
  3. 小屏幕使用导航 Drawer，导航后关闭；支持 Escape、遮罩关闭及焦点管理。
  4. 按共享 UI 契约新增 `DropdownMenu` 与 `Drawer` 基元。
- 非目标 / Non-goals：业务 API/RBAC 变化；用户/流程页主体变化；账户密码表单变化；全局 toast；桌面侧栏拖曳缩放。
- 验收标准 / Acceptance Criteria：
  1. AC1 顶栏：认证态顶栏固定显示当前邮箱/角色；菜单键盘与鼠标可用；修改密码进入 `/account`，登出清会话并到 `/login`。
  2. AC2 桌面导航：可展开/收窄；收窄时所有路由项仍有可访问名称；刷新后偏好保留；账号设置不再重复出现在侧栏。
  3. AC3 手机导航：小视口隐藏常驻侧栏，顶栏触发 Drawer；选择路由关闭 Drawer；Escape/遮罩关闭有效，焦点按契约管理。
  4. AC4 基元：DropdownMenu 支持触发、方向键/Home/End、Escape、外部关闭和焦点恢复；Drawer 有 modal 语义、焦点管理、Escape/遮罩关闭、滚动锁定；每个基元类型/实现/测试/示例/文档齐全。
  5. AC5 卫生：中英 i18n 对称；桌面和手机 e2e + `@a11y` 通过；`api/` 零 diff，`openapi-check` 绿。
- 约束 / Constraints：Vue3；状态由 App shell 持有，基元仅管理自身 open/focus 生命周期；偏好仅可存侧栏收窄值，不存认证态；浮层遵守 `packages/ui/docs/overlays.md` 与 `authoring.md`。
