# REQ-012 provider api_key Fernet 落库加密

> Origin: 用户 2026-09-29 定项——`docs/release.md:51` 二期 backlog 首项“api_key KMS 加密”；Plan 阶段追问定案为 Fernet 对称 + 双读兼容。

- 背景 / Background：`api_key` 现明文存于 `api/src/models.py:77`（`String(1024)`），读写经 `api/src/services/provider_service.py:31` `_auth_headers` 直接拼 Bearer。Controller 已只收不返（`api/src/controllers/models.py:25-30` Response 无 key），但 DB 泄露即全量泄露。`api/src/config.py:6-19` 无主密钥项，`api/pyproject.toml:6-20` 无 `cryptography`。
- 目标 / Goals：
  1. `api_key` 明文永不落库：写路径一律 Fernet 加密，读路径解密后拼 Bearer。
  2. 存量明文行双读兼容：老数据可用，下次写回自然收敛为密文，无需停机重写。
  3. 密钥单一来源 `API_MASTER_KEY`，dev 体验零变化，生产可配正式 key。
  4. 迁移版本化（`0002` 单 head），回滚可重放。
- 非目标 / Non-goals：外部 KMS/Vault 对接；密钥自动轮换与多 key 并存；`extra_headers` 内密钥治理；Response 返回 key（继续只收不返）；opencode-go 原生协议；Vector 下推；e2e runner。
- 用户与用例 / Actors & Use cases：
  - admin/super_admin：建/换供应商 Key（加密存），连通性检查照常用。
  - 运维：配 `API_MASTER_KEY`，跑 `upgrade head` 扩列。
  - 存量用户：老明文 Key 不中断，照常出 Bearer。
- 验收标准 / Acceptance Criteria（必填，每条可验证）：
  1. AC1 配置：`Settings.api_master_key`（env `API_MASTER_KEY`），dev 默认 `AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA=`（32 零字节，dev-only，文档明示生产必换）；非法格式在首次加解密时抛 `ValueError("主密钥无效")`，不泄明文不泄 key。
  2. AC2 加密 owner：新建 `api/src/libs/crypto.py`（`encrypt/decrypt/is_encrypted`）；`""→""` 直通；roundtrip `decrypt(encrypt(k))==k`；错 key 解密抛领域异常（controller 外不新增映射，service 内转 500 且不带明文）。
  3. AC3 写加密：`create/update` 非空 key 入库形态为 Fernet token（`gAAAA…`，长度 ≤2048），DB raw 与明文不等；空（None/''）保持语义不变（`provider_service.py:157/171` 注释沿用）。
  4. AC4 读双兼容：`_auth_headers`（`provider_service.py:30-33` 单点）解密后拼 `Bearer <明文>`；`fetch_models/test_connection/chat` 均经此单点；老明文行（非 `gAAAA` 起始或解密 `InvalidToken` 且非 Fernet 形态）按明文兜底可用；单测同时覆盖新密文行 + 老明文行。
  5. AC5 迁移 `0002`：`model_providers.api_key 1024→2048`，autogenerate 后人工核；`upgrade` 只改列类型不动数据；`downgrade` 逆向缩回 1024（截断风险仅 dev 文档化，生产禁降级）；`alembic check` 零漂移，单 head 无分叉。
  6. AC6 文档：`docker/envs/api.env.example` 增 `API_MASTER_KEY`（附生成命令），`docs/release.md` 增主密钥配置节 + 换 key 后果（老数据不可解，需重填 Key）。
  7. AC7 红线：controller schema 零改（`max_length=1024` 保持，明文长度约束不变）；`openapi-check` 绿；`conftest.py` sqlite+`create_all` 不动；`make lint/type-check/test` 全绿；`@smoke` 12 场景绿；日志/报错/Response 永不含明文 key。
- 约束 / Constraints：单 head；后续 revision 一律 autogenerate + 人工核；`compare_type=True` 延续；新增依赖仅 `cryptography>=44` 一个并 pin 大版本；`libs/` 保持业务无关（只读 settings，不引 models/service）；加解密为纯 CPU，事务内调用不算外部 IO；禁手写 DROP 绕过迁移。
- 歧义与假设 / Open questions & Assumptions：
  - 决议（用户已选）：Fernet 对称，不接外部 KMS；存量走双读兼容，不做一次性重加密停机迁移。
  - 默认（用户说 go 未细答，按此落盘，review 可改）：同列扩宽至 2048（不另立 `api_key_enc` 列）；缺 key 不做进程启动拦截，dev 默认 key 保零变化，生产靠文档强制换 key；轮换 = 换 key + 重填供应商 Key（无多 key 并存）。
- 影响面 / Impact（api/web/ui/e2e）：api（libs/config/service/models/迁移/依赖/文档）；web/ui 零改；e2e 零改（只收不返契约不变）。
