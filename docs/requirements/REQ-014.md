# REQ-014 opencode-go 原生协议

> Origin: 用户 2026-09-30 定项——`docs/release.md:60` 二期 backlog“opencode-go 原生协议”；Plan 阶段追问定案为列表+对话全切 + 凭证走环境变量。

- 背景 / Background：`ProviderType.OPENCODE_GO` 已存在（`api/src/models.py:63-65`）但走同一 OpenAI-compatible wire（`api/src/services/provider_service.py:1-5` 模块注释）；`fetch_models` 对 opencode_go 失败回退空列表（`:185`）。`api/scripts/spike_opencode_go.py`（PLAN-002 S2）上轮因无凭证只能给 downgrade 结论。本轮用户确认有可验证远端：地址 + Key 由使用者在模型供应商表单配置（现有 `type/base_url/api_key` 三栏，`api/src/controllers/models.py:17-22`），原生改造只切换该行的 wire 逻辑，不新增配置入口；build 经本地 API 对该供应商做连通验证，全程不经手 Key 明文。
- 目标 / Goals：
  1. 带凭证重跑 spike，结论回写 `provider_service` 模块注释（沿用 PLAN-002 模式）。
  2. `type == opencode_go` 时模型列表、连通检查、对话三处（`provider_service.py:185/204/216`）走原生协议；`openai_compatible` 路径零行为变化。
  3. 出站仍经 SSRF-safe 通道（`src/libs/http.py:assert_safe_url`）；失败回退语义不变（列表空、检查 `ok:false`、对话抛错上浮）。
- 非目标 / Non-goals：`openai_compatible` 通道任何改动；redis 缓存语义变更；controller/schema/迁移变更；web/e2e 形态变更；api_key 加解密逻辑变更（复用 REQ-012 解密后明文）。
- 用户与用例 / Actors & Use cases：admin 配 `opencode_go` 供应商 → 模型列表拉取 → 连通检查 → workflow llm 节点对话。
- 验收标准 / Acceptance Criteria（必填，每条可验证）：
  1. AC1 spike 证据：以用户配好的 `opencode_go` 供应商为目标做 wire 探测（经本地 API 建供应商/调连通，全程不经手 Key 明文；裸地址探测仅在必要时用 `OPENCODE_GO_*` 单次注入），verdict（`native-candidate` paths 或 `downgrade` + reason）回写模块注释；git/日志/TEST 永不出现凭证明文（仅记 host、状态码、截断 body 形态 ≤300 字符）。
  2. AC2 原生分发：三调用点按 `type` 分发原生 URL/头/payload/响应解析；monkeypatch 单测覆盖成功态 + 失败回退态。
  3. AC3 真实验证：对用户配好的 `opencode_go` 供应商做一次真实验证（经本地 API 调连通/模型列表，不经手 Key 明文），模型列表非空或连通 `ok:true`，证据记 TEST-014；若远端实际只通 OpenAI 形态则结论 downgrade、**不写推测性 client 代码**（无死代码）。
  4. AC4 通道隔离：`openai_compatible` 现有单测行为零变化（`test_model_providers.py` 全绿即证）。
  5. AC5 红线：`make lint/type-check/test` 全绿；`openapi-check` 绿（零 schema 改）；`@smoke` 全绿；出站 URL 全经 `assert_safe_url`（代码审计 + 内网地址单测已覆盖）。
- 约束 / Constraints：零新依赖（`httpx` 现有）；零 schema/迁移变更；供应商地址 + Key 由使用者在表单配置（不新增配置入口，密钥只存 DB 加密字段）；验证全程不经手 Key 明文，落盘物（注释/TEST/commit message）做脱敏审查；单测一律 monkeypatch 不打真实网络，真实验证仅 S3 一次。
- 歧义与假设 / Open questions & Assumptions：原生协议形态以 S1 spike 实测为准，PLAN 不预设路径/字段；远端抖动时 live 结果只做证据（mock 单测为门禁，live 失败不定 P0，见 PLAN R2）。
- 影响面 / Impact（api/web/ui/e2e）：api（service + spike 脚本 + 单测）；web/ui/e2e 零改。
