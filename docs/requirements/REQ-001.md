# REQ-001 Dify 同级平台（LangGraph 底层）

> Origin: 用户 2026-09-24 需求（11 条）+ plan 阶段追问定案。

- 背景 / Background：用户要自建 Dify 同级 LLM 应用平台，底层用 LangGraph；本地已有 `pgvector/pgvector:pg15`、`redis:6-alpine`、`nginx:latest`、`python:3.11-slim`、`oh-my-workspace-sandbox:latest` 等镜像在跑，要求优先复用本地镜像，开发期不频繁 `docker build`，确认发布才 build。
- 目标 / Goals：
  1. LangGraph 为 workflow 唯一执行底层（DAG JSON → LangGraph 图）。
  2. 模型支持通用 OpenAI-compatible + opencode-go 原生双通道，可配置切换。
  3. 登录 + RBAC（单租户三角色：super_admin / admin / member）功能权限。
  4. 用户管理（增删改查）+ 功能权限管理。
  5. 自定义 workflow（最小闭环节点）。
  6. 沙箱仅 Python（自建，以本地 `python:3.11-slim` 为底，无网络+超时+内存限）。
  7. VueFlow 自研流程画布（风格参考 langflow/dify，不引入 React）。
  8. database=postgres、vectordb=pgvector（同库 `pgvector/pgvector:pg15`）、缓存 redis（`redis:6-alpine`）。
  9. nginx（本地 `nginx:latest`）为唯一入口。
  10. 开发期本地直跑（`uv run --project api` + `pnpm dev` + infra compose），发布时才 `docker build`。
- 非目标 / Non-goals：多租户/workspace 两级授权、资源级 ABAC、React 版 langflow 直接嵌入、除 Python 外沙箱语言、Dify 全量节点（Agent/HTTP/定时等二期）。
- 用户与用例 / Actors & Use cases：
  - super_admin：管用户/权限/模型/全部 workflow。
  - admin：管用户（不含删 super_admin）、模型配置、workflow 发布。
  - member：编排与运行被授权 workflow。
  - 用例：登录→配模型→画布编排（LLM/Code/条件/检索）→发布→运行→查历史；admin 管用户权限；Python 代码节点进沙箱执行。
- 验收标准 / Acceptance Criteria（每条可验证）：
  1. AC1 LangGraph：含 llm/code/if/retrieval 的 DAG 可编译执行，`make test TARGET_TESTS=./api/tests/test_workflow_engine.py` 通过。
  2. AC2 模型双通道：两种 provider 增删改查+连通性检查通过，mock 测 `test_model_providers.py` 通过。
  3. AC3 登录+RBAC：未登录调业务 API 返回 401；member 调用户管理/模型写入返回 403；`test_rbac.py` 通过。
  4. AC4 用户+权限管理：三角色下用户 CRUD 与权限分配符合矩阵，API 单测通过。
  5. AC5 Workflow CRUD+版本/发布+运行历史：发布版本不可变，运行记录可查。
  6. AC6 沙箱：Python 正常/异常/超时三用例符合预期（超时杀死、无网络）。
  7. AC7 画布：VueFlow 可拖拽连线并存取 DAG JSON（以生成式客户端为准），`vue-tsc --noEmit` 通过。
  8. AC8 数据层：postgres+pgvector 同库可用，`pgvector` 扩展启用；redis 缓存命中可用。
  9. AC9 入口：nginx 反代 `/api/` `/` `/sandbox/`，`docker compose ps` 三 infra healthy。
  10. AC10 开发流：无 `Dockerfile.*` 新增即可本地全跑通；仅发布步骤含 `docker build`。
  11. AC11 镜像复用：compose 仅引用本地已有 tag（pg15/6-alpine/nginx:latest/python:3.11-slim），`docker images` 可查，无新增 pull。
- 约束 / Constraints：后端 `uv run --project api`、Vue3 禁 React（`web/AGENTS.md`）、controller 薄/service 编排/core 领域、Pydantic v2、SSRF-safe 出站、事务内无外部 IO、写注释即契约。
- 歧义与假设 / Open questions & Assumptions：
  - opencode-go 原生鉴权/模型列表协议未知→假设先做 spike，失败降级 OpenAI-compatible（PLAN-001 R1）。
  - Sandbox 内核级逃逸不在首版承诺内。
- 影响面 / Impact：api（新增）/ web（新增）/ ui（复用基元）/ e2e（新增 smoke）/ docker（新增 infra compose + nginx conf）。
