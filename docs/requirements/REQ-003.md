# REQ-003 Dify 式浅色换肤（壳 + 列表页先行）

> Origin: 用户 2026-09-28 反馈“画面太工程”，plan 阶段定案：Dify 式清爽浅色；范围=App 壳 + 登录/用户/模型/流程四页；画布保功能不动。

- 背景 / Background：`web/src` 零样式（无 CSS、无 Tailwind），五页裸语义 HTML；`packages/ui` 有契约无实现（`src/` 空）；App 壳无布局品牌。
- 目标 / Goals：
  1. 地基：Tailwind v4 接入 + `packages/ui/styles.css` + `web/src/styles.css` + Dify-like tokens（底 `#F4F6FB`、卡片白 `rounded-xl`、主色靛蓝 `#4F46E5`、焦点环可见）。
  2. 基元（四件套：类型+实现+测试+示例）：Button（primary/secondary/danger + loading）、Field（label/description/error 关联）、TextInput/Textarea、Select、Badge、EmptyState。
  3. 换肤：App 壳（侧边栏品牌+导航+角色/退出，顶栏标题）+ 登录（居中卡片）/ 用户（角色 Badge + 行删 + 新增卡）/ 模型（供应商卡 + 连通结果色）/ 流程（卡片网格 + 新建）。
- 非目标 / Non-goals：画布视觉定制（功能不动，只继承底色）；overlay/selection 重型基元（本轮原生 select + confirm）；新增 i18n key；全站暗色。
- 验收标准 / Acceptance Criteria：
  1. AC1 地基：`pnpm --dir web build` 通过；任一旧单测仍绿。
  2. AC2 基元：六基元（Button/Field/TextInput/Textarea/Select/Badge/EmptyState）四件套齐，包内单测全绿，story 可渲染。
  3. AC3 换肤：四页 + App 壳按设计稿落地；`vue-tsc` 绿；`@smoke` + `@a11y` 全绿；e2e 锚点文本（导航名/按钮文案/label）零改动。
  4. AC4 规范：事前一次授权条款写入 `docs/dev-spec/01-workflow.md`。
- 约束 / Constraints：Vue3 禁 React；Tailwind v4 canonical（`w-105`、`bg-linear-to-b`，状态经 data 属性）；基元唯一归属 `packages/ui`，web 只消费；生成式客户端不动；`@a11y` 保持绿（靛蓝 on 白对比度达标）。
