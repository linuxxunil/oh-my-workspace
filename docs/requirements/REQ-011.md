# REQ-011 alembic 正式迁移

> Origin: 用户 2026-09-29 定项——`docs/release.md:43` 二期 backlog 首项；触发方式：启动时自动 upgrade。

- 背景 / Background：现为 `API_AUTO_MIGRATE=1` + `create_all` 自举（`api/src/main.py:16-32`），无版本化脚本，生产无前滚/回滚手段。alembic 仅是未启用依赖（`api/pyproject.toml:15`，lock 1.20.0）。PLAN-001 S2 曾提脚手架但未落地。模型现状：10 张表、单文件 `api/src/models.py`、原生 PG ENUM ×2（`Role`/`ProviderType`）、vector 仅 `chunks.embedding`（`Vector(32)`，PG 外退 JSON）、零 `server_default`、JSON 全通用类型。
- 目标 / Goals：
  1. alembic 脚手架落地，单 head 基线 revision 覆盖全部 10 表。
  2. 启动时自动 `upgrade head` 替代 `create_all`（dev 体验零变化），seed 保持原样。
  3. 旧 dev 库 `stamp head` 兼容；一致性与回滚重放可验证；发布文档更新。
- 非目标 / Non-goals：seed 职责拆分；api_key KMS 加密；opencode-go 原生协议；Vector 原生检索下推；release Dockerfile 改动；单测切 PG。
- 用户与用例 / Actors & Use cases：开发者本地/发布前滚回滚；发布流程启动前迁移。
- 验收标准 / Acceptance Criteria（必填，每条可验证）：
  1. AC1 脚手架：`api/alembic.ini` + `api/alembic/env.py`（url 取 `settings.database_url`，`target_metadata=Base.metadata`，offline/online 双模式）；空库 `alembic current/history` 无报错。
  2. AC2 基线 revision `0001_baseline`：`upgrade()` 建全 10 表 + `CREATE EXTENSION IF NOT EXISTS vector` + 原生 ENUM + 全部索引/UQ/FK（autogenerate 生成后人工核对）；`downgrade()` 逆向全删（含 enum types drop，extension 保留）。
  3. AC3 启动接入：`auto_migrate=1` 时 lifespan 跑 `upgrade head` + 幂等 seed（seed 零改）；`=0` 时不碰 DB；`main.py:12` 的"后续"注释同步落地。
  4. AC4 旧库兼容：有表无 `alembic_version` 的 dev 库一次 `stamp head` 后 `upgrade` 为空操作，流程文档化。
  5. AC5 一致性：空 PG 库 `upgrade head` 结果与 `create_all` 等价（表/列/索引/约束/枚举 diff 为空），校验脚本随本轮落地、本地可重跑。
  6. AC6 回滚重放：`downgrade base → upgrade head` 可重放，之后 AC5 再绿。
  7. AC7 发布文档：`docs/release.md` 增"启动前跑 `alembic upgrade head`"步骤。
  8. AC8 红线：`conftest.py` sqlite+`create_all` 不动；`make lint/type-check/test` 全绿；controller/schema 零改动（`openapi-check` 绿、无需重生成）；`@smoke` 12 场景全绿；e2e reset（纯 API 删除）不受影响。
- 约束 / Constraints：单 head；后续 revision 一律 autogenerate + 人工核；`compare_type=True`；禁手写 DROP 绕过迁移；无新增依赖；无 Makefile 新增目标（验证直调 alembic CLI，不加戏）。
- 歧义与假设 / Open questions & Assumptions：无生产数据需迁移（dev/发布均可从空库前滚；旧 dev 库走 stamp）。
- 影响面 / Impact（api/web/ui/e2e）：api（lifespan + alembic 脚手架 + 校验脚本）；web/ui 零改动；e2e 零改动（schema 等价，reset 不碰 `alembic_version`）。
