# REQ-005 画布美化二期（全套节点 + 全类型表单）

> Origin: PLAN-003 deferred 项；用户 2026-09-29 定项——节点视觉全套、配置面板全类型表单。

- 背景 / Background：画布为 VueFlow 默认主题（灰盒节点、裸 JSON 配置），与新版浅色 UI 语言脱节；`@vue-flow/minimap`、`controls` 未装。
- 目标 / Goals：
  1. 画布 chrome：Minimap + Controls + 点阵背景 + 边样式（默认 slate、选中 indigo）。
  2. 自定义节点：start/llm/code/if/retrieval/end 六类型配色 + 选中环，保留 VueFlow `selected` 类语义（e2e 选中重试继续有效）。
  3. 全类型配置表单替代裸 JSON：start/end 无配置说明；llm（供应商下拉+模型+prompt+输出键）；code（代码等宽区+输出键）；if（变量+等于值）；retrieval（query+top_k+输出键）；e2e 画布步骤同步改写。
- 非目标 / Non-goals：代码高亮编辑器（等宽 textarea 足够）；边 label 手工编辑 UI；撤销/重做；后端任何改动。
- 验收标准 / Acceptance Criteria：
  1. AC1 chrome 落地且 `web-build` 通过。
  2. AC2 六类型节点配色 + 选中态；节点点击/选中/连线行为不变（@smoke 画布场景绿）。
  3. AC3 类型表单可用：code 场景经表单配出 `m=42`（@smoke）；裸 `config JSON` textarea 移除；`canvas.*` 中英同步。
  4. AC4 零后端改动：`make openapi-check` 绿且 diff 为空。
- 约束 / Constraints：Vue3 禁 React；节点模板放 web（领域归属，不进 packages/ui）；表单走 Field/TextInput/Select 基元；e2e 画布定位器随新表单更新（旧 `config JSON` 锚点作废为预期内）。
