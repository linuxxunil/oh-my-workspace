# REQ-013 pgvector 原生检索下推（混合语义保留，无索引先行）

> Origin: 用户 2026-09-30 定项——`docs/release.md:60` 二期 backlog“Vector 原生检索下推”；Plan 阶段追问定案为混合语义保留 + 无索引先行。

- 背景 / Background：现 `search` 在 `api/src/services/knowledge_service.py:58-68` 全量 load 该租户 chunks 后 Python 打分（0.7 关键词重合 + 0.3 余弦），O(N) 且向量计算全在应用层。列已是 PG 原生 `Vector(32)`（`api/src/models.py:85-105`，PG 外退 JSON），`api/alembic/versions/0001_baseline.py:78-89` 仅有 `ix_chunks_tenant_id/document_id`，无向量索引。embed 为 32 维确定性占位（`knowledge_service.py:21-27`），调用方为 `api/src/core/graph.py:66-74` retrieval 节点。
- 目标 / Goals：
  1. PG 路径向量排序下推：`ORDER BY embedding <=> :qv` 在 DB 内完成向量排序 + `LIMIT` 候选集。
  2. 混合语义不变：终排仍用现有 `tokens()/cosine()` 同一函数按 `0.7*kw + 0.3*cos` 打分取 `top_k`。
  3. 租户隔离：任何路径必带 `tenant_id` 谓词。
  4. sqlite 路径零改（单测/`conftest` 口径不动）。
- 非目标 / Non-goals：HNSW/IVFFlat 向量索引；tsvector/全文索引；embedding 模型与维度变更（`EMBED_DIM=32` 不动）；controller/web/e2e 契约变更；新迁移 revision。
- 用户与用例 / Actors & Use cases：member 运行含 retrieval 节点 workflow（`api/tests/test_workflow_engine.py:7-43` DAG）；admin 建文档后检索召回。
- 验收标准 / Acceptance Criteria（必填，每条可验证）：
  1. AC1 方言分发：`search()` 按 `db.bind.dialect.name` 分发；`postgresql` 走 `_search_pg`（DB 内 `ORDER BY ... LIMIT candidate` + Python 重排），其他走现有 `_search_python` 全量路径（与现实现逐行等价）。
  2. AC2 下推算子：PG 路径使用 pgvector 原生余弦距离（`Chunk.embedding.cosine_distance(qv)` 即 `<=>`），`WHERE tenant_id` + `ORDER BY distance` + `LIMIT candidate`，`candidate = max(top_k * 10, 50)`。
  3. AC3 混合公式复用：终排调用同一 `tokens()`/`cosine()`，权重 `0.7/0.3` 不变；候选集覆盖时与全量重排同 `top_k`（常规数据；病态分散数据允许差异并在 TEST 注明）。
  4. AC4 零迁移：无 alembic 新 revision，`alembic check` 零漂移，单 head 不变。
  5. AC5 回归：`test_workflow_engine.py` 全绿（含 retrieval 真实入库种子）；`conftest.py` sqlite 口径不动。
  6. AC6 红线：controller/schema 零改（`openapi-check` 绿）；`make lint/type-check/test` 全绿；`@smoke` 全绿。
- 约束 / Constraints：事务内无外部 IO（向量计算为纯 CPU/DB 本地查询）；逻辑收敛 `knowledge_service`；禁改 `EMBED_DIM` 与列类型；PG 专用分支必须被 `dialect.name != "postgresql"` 守卫，sqlite 单元测试永不触 pgvector 算子。
- 歧义与假设 / Open questions & Assumptions：候选数 `max(top_k*10, 50)` 为经验 covering 值（32 维小表全覆盖，大表为近似召回；索引待数据量起来后另起 REQ）。PG 路径 parity 以 infra PG 临时库实测为准（自建自删），本地 sqlite 套件不代证 PG 算子。
- 影响面 / Impact（api/web/ui/e2e）：api（`knowledge_service` 唯一改动点）；web/ui/e2e 零改。
