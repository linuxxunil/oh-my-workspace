# REQ-008 画布页 UX 整体优化

> Origin: 用户 2026-09-29 定项——画布页整体 / 右侧固定面板 / 页内运行历史。

- 背景 / Background：配置面板在画布下方、模板硬编码中文 5 处（违反 i18n 契约）、运行历史 API 调了却不展示、删除节点无确认、运行区裸 `textarea+pre`、画布高度写死 480px。
- 目标 / Goals：
  1. 双栏布局：右侧固定配置面板随选中出现/收起；画布高度自适应。
  2. i18n 补漏：画布页零硬编码文案；删除节点原生 confirm。
  3. 运行区基元化 + 页内运行历史列表（status Badge + error + 可展开 outputs）。
- 非目标 / Non-goals：dialog 基元；边 label 编辑 UI；撤销/重做；后端任何改动；流程列表/用户页/全局 toast 体系。
- 验收标准 / Acceptance Criteria：
  1. AC1 布局：右侧面板随选中出现/收起，画布高度自适应，`web-build` 通过。
  2. AC2 i18n：画布页零硬编码文案，`canvas.*` 中英对称；删除节点有 confirm。
  3. AC3 运行历史：run 后列表出现该次记录；`@smoke` 编排场景绿、`@a11y` 绿。
  4. AC4 零后端改动：`make openapi-check` 绿且 `api/` diff 为空。
- 约束 / Constraints：Vue3 禁 React；复用 `@/packages/ui` 基元；`role=status` 与 `aria-label=outputs` 锚点保留（e2e 依赖）；e2e 中文锚点随文案同步改写为预期内。
