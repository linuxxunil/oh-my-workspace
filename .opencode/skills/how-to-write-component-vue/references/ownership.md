# Ownership And Modules (Vue) / 归属与模块

写组件前先定归属方与模块边界，避免状态错位与越界引用。

- 按产品流程、路由、行为归属方建立垂直模块：单文件组件、组合函数、类型、存储片段、查询辅助、测试、小工具放在一起；页面与标签页文件夹按当前路由命名，不保留过时的父级分组。
- 跨模块只经过公开入口；不写只做转发的桶文件；只有成熟稳定且多方共用时才上提共享层。
- 状态、数据、加载态、空态、错误态、事件处理放在最低可用归属方；只有需要统一快照、跨卸载存活、协调提交或选择或批量操作或导航或跨区加载时才上提。
- 同一查询键在兄弟间复用共享缓存，不构成上提理由；不用庞大的视图组合函数代替属性传递；与提交相关的来源选择、默认值、校验、脏检查、载荷整形放在拥有提交的流程旁边。
- 谨慎新建包装组件与包装 DOM：必须真正拥有行为、校验、状态、无障碍、布局、外部库集成之一；模块逻辑不进入共享组件，不用布尔属性组编码某个具体模块。
- 页面区块加载态使用局部骨架屏；小型行内忙态才用 spinner。
- 组件边界类型使用生成类型或接口返回类型；属性按领域与接口角色命名，保持可追溯；不把枚举、联合类型、可空类型提前放宽为普通字符串。
