# State And URL Ownership (Vue) / 状态与地址归属

三类状态各有归属：本地交互态、跨组件共享态、服务端缓存态。

## Owner Selection / 归属方选择

- 单组件同步态（对话框、菜单、确认框、字段草稿、本地选择）放在组件本地 `ref` 或 `reactive`。
- 兄弟需要单一真相、跨隐藏或卸载步骤保持时，使用模块级 Pinia 存储；高频交互态（例如画布拖拽）使用专用存储模块。
- 服务端与缓存态一律使用 Vue Query；低频偏好（已关闭的提示、界面默认值）才用持久化插件；运行中的实时应用态不进入本地存储。

## Forms / 表单

- 遵循 `packages/ui/docs/forms.md` 的受控性与 `overlays.md` 的挂载寿命；查询回填默认值的表单等默认值就绪后再建会话；默认值只初始化当前挂载；不拿生成键当常规重置手段。
- 校验、来源优先级、兜底、脏检查、载荷组装放在拥有提交的流程；布尔态、禁用态、默认标签页、加载文案从当前状态派生，不镜像多份来源。

## Route And URL / 路由与地址

- `vue-router` 的路径参数与查询参数是地址身份唯一归属方；可分享的筛选、标签页、面板、分页、搜索放在地址栏；一次性导航信号与瞬态界面状态不进入持久订阅。
- 同一路由内只选单一身份来源，不既灌入存储又层层透传同一标识。

## Store And Query / 存储与查询分工

- 模块存储按依赖排序：类型常量、状态、派生取值（业务事实）、动作（命令与提交编排）；异步由 Vue Query 拥有，不在存储内手写加载态、错误态、在途标志。
- 读取查询结果使用字段级 `computed` 或 `select`，不订阅整个观察者；对话框各自生命周期独立，不经由无关属性透传打开态。
