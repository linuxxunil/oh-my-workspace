# Testing Review (Vue) / 测试评审

只为稳定可观察契约补充测试，不为覆盖率数字加测试。

- 值得覆盖：交互结果、路由与地址与持久化与权限与数据流、可达的加载态与成功态与失败态与空态、无障碍语义、可复现的回归。
- 不值得覆盖：单纯撑文件覆盖率、渲染不崩溃、类型系统已排除的输入、实现细节（内部状态、组合函数调用顺序、私有 DOM 结构）。
- 边界：纯函数用单测；可复用的组合函数才直接测试，否则经由拥有它的组件测试；组件行为用 Vue Test Utils 加 happy-dom；跨模块用集成测试；浏览器测试须同时满足三条准入（真实价值、增量证据、忠实边界）。
- 模拟只放在真实边界（网络、导航、外部 SDK、重型提供者），不模拟被测的界面基元；不发真实网络请求；查询测试每个用例新建客户端。
