# Frontend Testing (Vue) / 前端测试

本技能不设平行政策，只路由到包内测试真相并执行。

- `web/`：`web/docs/test.md` 拥有测试边界、运行环境、验证命令。
- `packages/ui/`：`packages/ui/docs/testing.md` 拥有基元测试边界、Storybook 用法、验证命令。

按归属方要求运行验证命令；缺失的行为覆盖与低价值测试同等看待，该删即删；报告已验证的契约与剩余缺口。
